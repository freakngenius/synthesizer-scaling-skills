# Synthesizer Scaling skills

Two skills for an AI agent (Claude, Polar or similar) that coach an idea through the Synthesizer Scaling program.

- `synthesizer-scaling-coach`: the coach. Takes an idea through Backbone, Launch Prep, Launch Attract, Convert, Deliver and post-launch. Start here.
- `synthesizer-scaling-library`: the searchable archive the coach looks things up in (master index, distilled notes, aggregated scripts and benchmarks, raw transcripts).

## Install

Copy both folders into your agent's skills directory (each folder has a `SKILL.md`). Keep them side by side, since the coach reads the library.
