# Synthesizer Scaling library

Reference material only. The coaching behavior lives in `synthesizer-scaling-coach`. Use this skill to look things up, never to improvise program content.

## How to look something up (cheapest first)

1. `master-index.md`: find the lesson or call by title. Each entry has the Skool URL, the Notion archive page, the original Google Docs and Sheets, the distilled notes file and the raw transcript file.
2. `aggregates/`: one file per kind of information, grouped by source, copied from the notes.
   - `scripts.md`: verbatim scripts, templates, hooks, questions
   - `benchmarks.md`: numbers (rates, counts, prices, timings) with their context
   - `mistakes.md`: warnings and do-not rules
   - `examples.md`: member and company cases
   - `resources.md`: docs, sheets, tools and links mentioned
3. `notes/`: the distilled notes for one lesson or call (summary, frameworks, tactics, scripts, examples, mistakes, numbers, resources, best-used-when, open questions). Read the whole file for one source.
4. `raw/`: full transcripts. Open only for exact wording. The files are large (80,000 to 130,000 characters for a call). Search with grep, read only the matching region.

## Known gaps and cautions

- Not captured: the locked Attract, Convert, Deliver courses and Mastermind, about 65 call recordings without transcripts, four Backbone Review YouTube videos, the onboarding PDF. If asked about them, say they are not in the archive.
- Transcripts are auto-generated: names and terms are sometimes wrong ("School" for Skool, "icing tied" for rising tide). Notes correct obvious errors.
- Notes are distilled by AI from the transcripts. Check an important number or script against the raw file before the user relies on it.
- Several Attract calls are Skool platform specific and dated. Several calls announce experiments, not validated methods.
- Two uploaded transcripts (1 and 4) duplicate existing calls; the other uploaded transcripts (2, 3, 5) are in the index without their original post titles.
- Google Docs and Sheets in the index belong to the program. Users make their own copy before editing.
